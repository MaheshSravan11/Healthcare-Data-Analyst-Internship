# Healthcare Data Analyst Internship

This repository contains my work for the Healthcare Data Analyst Internship.

## Task 1 – Project Planning and Strategy

The project focuses on analyzing healthcare data to understand factors associated with 30-day hospital readmission among diabetic patients.

### Dataset
Diabetes 130-US Hospitals dataset from the UCI Machine Learning Repository.

### Task 1 Deliverable
- Project planning and strategy document
- Project objectives and research questions
- Data source and key metrics
- Planned methodology
- Ethical considerations
- Risk assessment and contingency planning
- Project timeline

More tasks and analysis will be added to this repository as the internship progresses.
